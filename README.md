## 🚀 Comment Lancer et Déployer le Site ?

### 1. Test immédiat en local
* Double-cliquez simplement sur **`index.html`** pour ouvrir le site dans votre navigateur (Chrome, Edge, Safari, Firefox).

### 2. Déploiement en ligne gratuit (en 2 minutes)
Vous pouvez mettre ce site en ligne gratuitement avec un nom de domaine personnalisé :
* **Netlify Drop** (le plus simple) : Glissez-déposez simplement le dossier `JML` sur [app.netlify.com/drop](https://app.netlify.com/drop).
* **Vercel** ou **GitHub Pages** : Idéal pour un hébergement rapide avec certificat SSL HTTPS automatique.
* **Hébergeur classique** (OVH, Hostinger, O2Switch) : Transférez les fichiers via FTP dans le dossier `public_html` / `www`.
