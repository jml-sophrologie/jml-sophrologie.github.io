## 🛠️ Caractéristiques techniques

- **Frontend :** HTML5 sémantique, CSS3 moderne (Variables CSS, Flexbox & CSS Grid), JavaScript vanilla.
- **Réservation en ligne :** Module interactif intégré [Cal.com](https://cal.com/jml-sophrologie) synchronisé en temps réel avec Google Agenda.
- **Design & Ergonomie :** 100 % responsive (smartphone, tablette, desktop), typographie soignée (*Cormorant Garamond* & *Plus Jakarta Sans*).
- **SEO & Données Structurées :** Balisage Schema.org (HealthAndBeautyBusiness, FAQPage) et référencement local Alpes-Maritimes.
